# DFS Protocol — Contest Rules

## Rule 0: Create No Victims
No mechanic, card, player action, or contest ruling could result in a victim being created.
This rule supersedes all other rules in every situation.
The Wizard of Iz applies Rule 0 as the deciding standard in all contested rulings.

### Tier 3: Sovereign Level

## The Three Questions Framework

Every contested ruling in DFS Protocol is resolved by applying three questions in sequence:

### Question 1: Does this create a victim?
- If yes — the action is void. Rule 0 applies. No exceptions.
- If no — proceed to Question 2.

### Question 2: Is this grounded in intrinsic reality?
- If yes — the action proceeds with full protocol backing.
- If no — apply the Fiction Die result and flag for Banker influence review.

### Question 3: Does the human-in-the-loop confirm?
- The Wizard of Iz makes the final call.
- No automated outcome overrides the Wizard of Iz when victims are at risk.
- Wizard confirmation locks the ruling for the remainder of the round.

## Contest Conduct Standards
- All players operate under Rule 0 at all times
- Banker archetypes may not be played by a human player against another human player in a way that creates a real-world victim
- The Wizard of Iz role must be filled before Tier 2 or Tier 3 play begins
- All rulings are final once the three-questions framework is applied
- Standing Order is active throughout all contest play
